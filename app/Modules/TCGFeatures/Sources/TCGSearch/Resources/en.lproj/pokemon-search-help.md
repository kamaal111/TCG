## Card name

```
Charizard
```

Search by a name in any supported language.

## Name + card number

```
Charizard ex 199
```

Add a card number to narrow your search.

## Set + printed number

```
sv5m 072/071
```

Use the set code and the full number printed on the card, including leading zeros and the total.

## Exact set ID + card number

```
sv5m_ja 72
```

A full set ID targets that expansion. The `_ja` suffix identifies a Japanese set.

English and Japanese cards are searched together. English names can also match translated names when available.
